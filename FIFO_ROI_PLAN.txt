📚 ЧТО ТАКОЕ FIFO?
─────────────────────────────────────────────────────────────────────────────

FIFO = First In, First Out (Первый пришел - первый ушел)

Это метод учета товаров при их продаже.

ПРИМЕР:

У вас есть товар "Кружка":

Поставка 1 (15 января): 100 шт по 500₽
  └─ Осталось: 45 шт
Поставка 2 (10 февраля): 150 шт по 520₽
  └─ Осталось: 150 шт

ПРОДАЕТСЯ: 50 кружек

По методу FIFO списываем так:
  1. Берем 45 шт из Поставки 1 (15 янв) по 500₽
     └─ Себестоимость: 45 × 500₽ = 22,500₽

  2. Берем 5 шт из Поставки 2 (10 февр) по 520₽
     └─ Себестоимость: 5 × 520₽ = 2,600₽

ИТОГО себестоимость 50 шт: 22,500₽ + 2,600₽ = 25,100₽

ЧАСТЬ 3: ФОРМУЛЫ РАСЧЕТА
═════════════════════════════════════════════════════════════════════════════

📐 ОСНОВНЫЕ МЕТРИКИ:

1️⃣ СЕБЕСТОИМОСТЬ ПРОДАННЫХ ТОВАРОВ (COGS)
   = Сумма стоимости товаров по методу FIFO
   = 25,100₽ (в примере выше)

2️⃣ ВЫРУЧКА (REVENUE)
   = Сумма, полученная от Ozon за доставленные товары
   = 50 шт × 1000₽ = 50,000₽

3️⃣ ВАЛОВАЯ ПРИБЫЛЬ (GROSS PROFIT)
   = Выручка - Себестоимость
   = 50,000₽ - 25,100₽ = 24,900₽

4️⃣ ВАЛОВАЯ МАРЖА (GROSS MARGIN %)
   = (Выручка - Себестоимость) / Выручка × 100%
   = 24,900₽ / 50,000₽ × 100% = 49.8%

5️⃣ ВСЕ РАСХОДЫ
   = Комиссия Ozon + Логистика + Реклама + Возвраты + Прочее
   = 4,500₽ + 1,200₽ + 800₽ + 500₽ + 400₽ = 7,400₽

6️⃣ ЧИСТАЯ ПРИБЫЛЬ (NET PROFIT)
   = Валовая прибыль - Все расходы
   = 24,900₽ - 7,400₽ = 17,500₽

7️⃣ ROI (Return On Investment)
   = (Чистая прибыль / Себестоимость) × 100%
   = 17,500₽ / 25,100₽ × 100% = 69.7%

8️⃣ РЕНТАБЕЛЬНОСТЬ ПРОДАЖ (ROS - Return On Sales)
   = (Чистая прибыль / Выручка) × 100%
   = 17,500₽ / 50,000₽ × 100% = 35%

ЧАСТЬ 5: АЛГОРИТМ FIFO РАСЧЕТА
═════════════════════════════════════════════════════════════════════════════

🔧 ПСЕВДОКОД FIFO РАСЧЕТА:

```
ФУНКЦИЯ calculate_fifo_cost(offer_id, quantity_sold):
    purchases = загрузить purchases.json
    filtered = отфильтровать поставки по offer_id
    sorted = отсортировать по дате (старые первыми) ← FIFO!

    total_cost = 0
    fifo_breakdown = []
    remaining = quantity_sold

    ДЛЯ КАЖДОЙ поставки В sorted:
        ЕСЛИ remaining == 0:
            ВЫХОД

        available = поставка.remaining
        take = МИН(remaining, available)

        cost = take × поставка.purchase_price
        total_cost += cost

        fifo_breakdown.ДОБАВИТЬ({
            purchase_id: поставка.id,
            quantity: take,
            unit_cost: поставка.purchase_price,
            total_cost: cost
        })

        поставка.remaining -= take
        remaining -= take

    ВЕРНУТЬ {
        total_cost: total_cost,
        breakdown: fifo_breakdown
    }
```

КЛЮЧЕВОЙ МОМЕНТ: Сортируем поставки по дате!
Старые (раньше добавленные) списываются первыми!

🔗 КАК ПОЛУЧИТЬ ДАННЫЕ ДЛЯ РАСЧЕТА:

1️⃣ ВЫРУЧКА (из /v2/posting/fbo/list):
   postings → products[].price × products[].quantity
   = цена покупателя × количество

2️⃣ ВЫПЛАТА ПРОДАВЦУ (из /v2/posting/fbo/list → financial_data):
   financial_data.products[].payout
   = выручка после вычета комиссий

3️⃣ РАСХОДЫ (из /v3/finance/transaction/list):
   • sale_commission → Комиссия Ozon
   • services[] → Услуги Ozon (логистика, возвраты)
   • delivery_charge → Доставка
   • Реклама (из Performance API)

4️⃣ СЕБЕСТОИМОСТЬ:
   ← Берем из purchases.json (вручную добавляется)
   ← Рассчитывается по FIFO при каждой продаже
